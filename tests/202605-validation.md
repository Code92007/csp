# 202605 验证记录

验证日期：2026-11-24。对应同目录的五份 C++17 源码及 [完整题解](../202605/README.md)。本版已根据 review 修订，重构代码尚未重新提交在线评测。

五题均以 Apple Clang 21、`-std=c++17 -O2 -Wall -Wextra` 编译，无警告。本机 Clang 通过临时兼容头提供 `bits/stdc++.h`，交付代码保持 GNU 竞赛写法；本轮未使用 GCC 编译。

| 题目 | 独立验证 | 结果 |
| --- | --- | --- |
| A | 一组 100 个输入覆盖全部小数位和整数奇偶组合，另检验整数部分上界 | 通过 |
| B | 100 组枚举机器人数量对拍，另检验 3 组初始苹果数为 `10^18` 的边界 | 通过 |
| C | 90 组使用绝对时间轴的独立模拟，核对收益、结束时间和死锁 | 通过 |
| D | 110 组区间划分 DP 对拍，每组检查全部子区间 | 通过 |
| E | 24 组合法操作穷举，以及 2042 组独立小规模 DP 对拍 | 通过 |

上述两套独立校验合计 2367 组；另通过全部 8 个保存样例。

用户 review 后，B 题去掉极短赋值分支的大括号，C 题改为声明数组后逐轮显式 `memset` 清零，D 题去掉裸作用域并用 `clear()`、`rehash(0)` 保留哈希表回收时机。B、C、D 已重新以相同选项编译，无警告；重跑原有的 100、90、110 组独立对拍和各自保存样例，全部通过。另复核 B 的 3 组大整数边界、D 的两组百万规模数据。此次复用已有测试集，不把重复执行计为新的独立组数。

D 题额外运行两组百万点数据：全零序列配百万次查询，答案均为区间长度；隔位前缀互异的序列检查没有必胜区间时的倍增哨兵，答案均为 0。

E 题的 2042 组 DP 对拍包括 `n≤6` 的全部 1442 棵有标号树和 `n=7…10` 的 600 棵随机树。此外运行了 7 组十万点构造：三种链、两种星形、随机树和扫帚树，均检查输出为完整排列；对答案可直接确定的链与星形，另检查输出为升序。大规模运行和排列检查不等于大规模最优性证明。
