## 压力检查

```sh
make build SESSION=202609 PROBLEM=E
python3 tests/stress_202609E.py
```

压力脚本使用 10 万节点链、40 种颜色、`k=4`、初始全亮、10 万次随机开关。优化后的本机最近一次记录约 2.6 秒、峰值约 174 MiB，见 `stress-202609E-report.json`。这是本机数据，不能作为其他机器或正式评测时限的保证；[数梦 OJ 100 分记录](https://oj.shumeng.tech/record/6adce90ea67df0b81749bfe2)另行核对。

这项检查只核对进程成功结束和输出行数为 `q+1`，大规模输出没有独立答案基准。正确性证据来自小规模对拍及题解中的算法论证，二者不能混为一谈。

编译命令为 C++17、`-O2 -Wall -Wextra`。未提交正式 OJ，不存在官方 AC 记录。
